# Datafatech - React + Tailwind CSS + Node.js

Yeh project **React**, **Tailwind CSS v4**, aur **Vite** ke sath setup ho chuka hai.

## Requirements
- **Node.js**: `v24.22.0` (Already installed)
- **NPM**: `v11.19.1` (Already installed)

---

## How to Run Development Server

Terminal mein yeh command chalayein:

```bash
npm run dev
```

Browser mein open karein:
```text
http://localhost:5173
```

---

## Available Scripts

- `npm run dev`: Development server start karta hai
- `npm run build`: Production build banata hai (`dist/` folder)
- `npm run preview`: Production build ka local preview dikhata hai
